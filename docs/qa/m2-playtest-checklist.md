# M2 플레이 테스트 체크리스트 (10-1)

> 사용자가 직접 플레이하며 채우는 기록지입니다. 기록은 10-2(수치 조정)의 유일한 근거입니다. 시뮬레이션은 하지 않았으므로 아래 목표는 **가정**입니다.
> 칸이 많아 보여도 **1번 표(1런 시간표)와 3번 표의 2런 시간표**만 채워도 10-2를 진행할 수 있습니다. 나머지는 가능한 만큼만 적어 주세요.

## 0. 시작하는 법
- [ ] 배포 주소 https://park-jong.github.io/enhance/ 를 연다 (`test.html`은 강화 100%라서 **시간 측정에 쓰지 않음**)
- [ ] 예전 화면이 남지 않게 **Ctrl+Shift+R**(강력 새로고침)을 한다. 아직 push 전이면 로컬 `index.html`을 연다
- [ ] 새 저장으로 시작: 개발자 도구(F12) 콘솔에 `localStorage.removeItem('sword-enhance-v2')` 입력 후 새로고침 (또는 시크릿 창/새 브라우저 프로필)
- [ ] 평소처럼 플레이. 치트·콘솔 조작 금지. 소모품은 평소 습관대로 쓰기
- [ ] 시간은 **실제로 접속해서 플레이한 시간**(탭을 닫거나 멈춘 시간, 오프라인 보상 제외). 스톱워치나 휴대폰 타이머를 쓰고, 자리를 비울 때는 멈추기
- 시작 일시 / 기기·브라우저 / 플레이 스타일(수동 위주, 자동 병행 등): __________
