## 1. 후보 취사 결과
기존: `bless`(축복 주문서), `protect`(파괴 보호권, F2 통합), 모루(F3 장비). **신규 4종만 채택**(총 소모품 id: bless, protect, keepdown, sure, booster, seal + 모루).
| 후보 | 결정 | 이유 |
| --- | --- | --- |
| 하락 방지 주문서 | **채택 `keepdown`** | 하락(+10 이상 실패)을 막아 "파괴 보호"와 다른 위험(하락)을 다룸. 판단 지점이 분명 |
| 확정 강화권 | **채택(수정) `sure`** | +9 이하에서 100% 성공(+10 도달까지). 파괴가 시작되는 +5~+9 구간의 확실한 방어 수단 |
| 단계 복구권 | **제외** | 파괴 보호권 + 칸 비움 규칙과 역할이 겹치고, "파괴된 검"을 추적해야 해서 저장/UI 복잡 |
| 행운의 부적(시간제 확률) | **제외** | 축복 주문서/모루와 겹치고 확률 상한을 더 압박. 시간제 확률은 M2 F13 이벤트와 충돌 |
| 골드 부스터 | **채택 `booster`** | 방치(F1) 가치를 키우는 유일한 시간제 아이템. 확률에 영향 없음 |
| 감정 인장 | **채택 `seal`** | 판매·납품 시점의 선택(언제 쓸지)을 만듦. 확률에 영향 없음 |
| 의뢰 갱신권 | **제외** | 골드 새로고침(`QUEST_REROLL_COST`)으로 대체. 아이템 종류 증가 방지 |

| `seal` | 감정 인장 | 다음 판매 또는 납품 골드 ×`SEAL_MULT`(1.3) | 2,000 | 불가 | 어려움 | - | 해당 없음 | 99 |
| 모루 | (m1-anvil-ore 참조) | | | | | | **포함** | |
- `PRICE` 객체는 기존 `{bless:1500, protect:4000}`에 신규 키를 추가.
- 상점 탭에는 6종 + `anvil_1` + 새 검 구매를 나열(해금 표시는 overview 참조).
- 부스터 중복 사용: 지속 중 추가 사용 시 `boostUntil`을 연장(`boostUntil = max(now, boostUntil) + duration`), 최대 잔여 `BOOSTER_MAX_MIN`(60분). 상점 구매(즉시 적용)와 인벤토리 사용 모두 같은 규칙이며, 연장 후 잔여가 60분을 넘게 되면 버튼을 비활성.
- 수치(가격·파편가)는 m1-balance 확정값. 부스터 가격을 최고 단계에 연동하고 상점 구매를 즉시 적용으로 한 이유: 고정가 3,000G는 +10 이상에서 상시 ×1.5 수입이 되고, 연동가를 인벤토리에 쌓게 하면 낮은 단계에서 싸게 사 두는 악용이 생긴다.
- 인장은 `use.seal`토글을 판매/납품 확인 직전에 켜고, 실제 판매·납품이 실행될 때만 1장 소모.

## 3. 한 번의 강화에서 같이 쓰기
트레이 행(강화 시도용 토글): `bless`, `anvil`, `protect`, `keepdown`, `sure`.
| 조합 | 가능 | 비고 |
| --- | --- | --- |
| bless + anvil | O | 합산 후 상한 적용 |
| bless/anvil + protect | O | |
| bless/anvil/protect + keepdown | O | |
| protect + keepdown | O | 서로 다른 실패 유형을 방어 |
| `sure` + 그 외 모두 | **X** | `sure` ON이면 나머지 토글은 비활성(회색)·강제 해제. 낭비 방지 |
| 활성 검 `l ≥ SURE_MAX_TARGET` | `sure` 토글 비활성 | "+10 이상에서는 사용할 수 없습니다" |
| `keepdown` + 활성 검 `l < DROP_FROM` 또는 `l ≥ KEEPDOWN_MAX_LV` | 비활성 | 하락이 없는 단계에서는 의미 없음 / +15 이상은 사용 불가. "+10~+14에서만 유효" |
| `protect` + `DESTROY[l]==0` | 비활성 | |
- `booster`, `seal`은 트레이가 아닌 별도 위치(`booster`: 자원바/방치 탭 사용 버튼, `seal`: 판매/납품 확인 단계)에서 사용.

## 4. 시도 1회당 소모 순서
```
1) 검증: 골드 >= cost(l); 선택된 토글의 보유량/조건 충족 여부(미충족 토글은 자동 해제하고 토스트)
2) 시작 시점 차감(굴리기 전, 즉시 저장):
     gold -= cost(l)
     bless 토글 ON → inv.bless -= 1
     sure  토글 ON → inv.sure  -= 1
     anvil 토글 ON(sure 아님) → 장착 모루 dura -= 1
3) 확률 계산 chances(sword, {bless, anvil, sure})   // m1-pity-cap
4) 굴리기
5) 결과별 후처리(결과가 발생했을 때만 소모):
     성공: pity=0, prot=PROTECT_USES (단계 변경)
     파괴: protect 토글 ON & 조건충족 → inv.protect -= protectNeed(l), prot-=1, pity+=1
           아니면 파괴(파편 지급, 칸 비움)
     실패: DROP_FROM ≤ l < KEEPDOWN_MAX_LV 이고 keepdown 토글 ON & inv.keepdown ≥ 1 → inv.keepdown -= 1, 단계 유지
           l ≥ DROP_FROM 이고 keepdown 없음 → 하락(prot=PROTECT_USES)
           pity += 1
6) 저장 후 UI 갱신. 보유량이 0이 된 토글은 자동 해제
```
- `bless`, `sure`, 모루 내구도는 **시도 시작 시 소모**(결과와 무관), `protect`, `keepdown`은 **효과가 실제로 발동했을 때만** 소모. 트레이 라벨에 소모 시점 표기("사용 시 소모"/"발동 시 소모").
- 토글 상태 `use.*`는 저장되므로, 보유량이 부족해지면 로드/렌더 시 자동으로 false.

## 5. 트레이 UI
- 강화 버튼 위에 "소모품" 트레이: 행당 [체크박스] 아이콘 이름 `보유 n` · 효과 한 줄 · 상태 뱃지(비활성 사유). 기본 접힘 없음(최대 5행).
- 행 순서: ✨축복 / 🔨모루 / 🛡️보호 / ⬇️하락 방지 / 🎯확정 강화. 현재 단계에 무효인 행은 회색 + 사유 한 줄(숨기지 않음, 사용자가 존재를 인지하도록).
- 확률 보너스 포함 항목(축복, 모루)에는 `+N%p` 표기, 상한 도달 시 "효과 없음" 경고(m1-pity-cap).

## 열린 질문 (사용자 확인 필요)
1. `sure` 허용 범위를 +9까지로 둠(+10 달성 이후 단계는 불가). 사용자가 더 넓게(+12 등) 원하는지.
2. 단계 복구권/행운의 부적/의뢰 갱신권을 제외한 것에 동의하는지(총 신규 4종).
3. 부스터를 오프라인 시간에도 지속(권장) vs 접속 중에만.

## 수용 기준 (Acceptance criteria)
1. Given `sure` 보유, +7 검 / When 토글 ON 후 강화 / Then 성공 100%·파괴 0%, `inv.sure`-1, `bless` 등 다른 토글은 비활성이며 소모되지 않는다.
2. Given 활성 검 +10 / Then `sure` 토글은 비활성이고 이유 문구가 표시된다.
3. Given `keepdown` 보유, +12 검, 토글 ON, 실패(비파괴) 결과 / Then 단계 유지, `inv.keepdown`-1, 하락 없음. 성공/파괴 결과 / Then `keepdown`은 소모되지 않는다.
4. Given +9 검 또는 +15 이상 검에서 `keepdown` 토글 / Then 비활성(+9: 하락 없는 단계, +15 이상: `KEEPDOWN_MAX_LV` 초과).
5. Given `bless` ON, 성공 또는 실패 무관 / Then `inv.bless`가 시도마다 1 감소한다.
6. Given `protect`와 `keepdown`을 동시에 ON / Then 파괴 시 `protect`만, 비파괴 실패 시 `keepdown`만 소모된다.
7. Given 보유 0인 아이템의 `use.*`가 true로 저장된 상태에서 로드 / Then 토글이 false로 정리된다.
8. Given `booster` 사용(인벤토리) 또는 상점 구매 / Then `boostUntil = now + 10분`, 수동 사냥 골드 ×1.5(소수점 내림), 종료 시각 후 배율 해제. 재사용 시 연장되며 잔여 60분을 넘지 않는다. 상점 구매는 `inv.booster`를 늘리지 않고, 가격은 `boosterPrice(best)`(예: `best=10` → 16,900G, `best≤7` → 3,000G).
9. Given `seal` 토글 ON으로 판매 / Then 판매 골드가 `floor(sell × 1.3)`, `inv.seal`-1. 판매를 취소(확인 단계 이탈)하면 소모되지 않는다.
10. Given 파편 교환/상점/퀘스트로 `inv`가 99일 때 / Then 구매·교환 버튼이 비활성이고 퀘스트 보상은 파편으로 대체된다.
11. Given 시도 시작 직후 새로고침 / Then 결과(굴림)와 모든 소모·보상이 시도 시작 시점에 확정·저장돼 있어(연출은 결과 표시만 늦춤) 새로고침으로 결과를 다시 굴리거나 소모만 사라지는 일이 없다. (구현: 4)의 굴리기와 5)의 후처리를 연출 대기 전에 동기 실행하고 `save()` 후 연출 재생.)
