# M1 모루(F3) + 광석 · 제작 · 수리(F8)

> 저장 필드: `anvils[]`, `anvilEq`, `ore.*`, `use.anvil`, `stats.crafted` (`m1-storage.md` §3).

## 1. 결정 요약
| 항목 | 결정 |
| --- | --- |
| 등급 수 | 3등급: `anvil_1` 철 모루 / `anvil_2` 강철 모루 / `anvil_3` 미스릴 모루 |
| 확률 보너스 | `ANVIL_BONUS[g]` = +2 / +3 / +4 %p (m1-balance 확정. 축복 + 미스릴 = +10 이상 상한 14). 확률 보너스 상한에 **포함** |
| 장착 | 한 번에 **1개만 장착**(`anvilEq`). 장착은 영구 상태, 실제 사용은 강화 시도마다 토글 `use.anvil` |
| 축복 주문서와 중첩 | **중첩 가능**. 단 둘의 합은 합계 상한(m1-pity-cap)이 자름 |
| 내구도 소모 | **사용(토글 ON) 한 시도마다 -1**(성공·실패·파괴 무관). 예측 가능성 우선 |
| 내구도 0 | **사라지지 않고 "파손" 상태**. 파손 모루는 보너스 0, 토글 불가, 광석으로 **수리** 후 재사용. 모루는 소모품이 아니라 수리 가능한 장비 |
| 사용 가능 단계 | 전 단계 사용 가능(UI 상 +5 이상에서만 토글 노출. 낮은 단계에서 내구도 낭비 방지) |
| 보유 한도 | `ANVIL_OWN_MAX`=6개(파손 포함) |
| 확정 강화권(`sure`)과 | 동시 사용 불가, 내구도 소모 없음 (consumables 참조) |

## 2. 모루 등급 표 (m1-balance 확정값)
| 등급 | id | 보너스 `ANVIL_BONUS` | 내구도 `ANVIL_DURA` | 제작 비용(광석+골드) `ANVIL_CRAFT` | 수리 비용(내구도 전부 복구 기준) `ANVIL_REPAIR` |
| --- | --- | --- | --- | --- | --- |
| 1 | `anvil_1` | +2%p | 30 | iron 60 | iron 30 |
| 2 | `anvil_2` | +3%p | 40 | iron 100, silver 60, 5,000G | iron 40, silver 40 |
| 3 | `anvil_3` | +4%p | 50 | silver 150, mithril 80, 20,000G | silver 50, mithril 50 |
- 수리는 **부분 수리 가능**: 비용 = `ceil(ANVIL_REPAIR × 복구할 내구도 / ANVIL_DURA)`(각 광석별 올림, 최소 1). UI 버튼은 "전부 수리"만 제공(단순화), 비용은 위 비례식.
- 수리에는 골드 불필요(광석 싱크). 제작에만 골드 사용.

## 4. 광석 (F8)
| 광석 | id | 해금 조건 | 용도 |
| --- | --- | --- | --- |
| 철광석 | `ore_iron` (`ore.iron`) | 처음부터 | 1·2등급 제작/수리 |
| 은광석 | `ore_silver` (`ore.silver`) | `best ≥ ORE_UNLOCK_LV.silver`(7) | 2·3등급 |
| 미스릴 광석 | `ore_mithril` (`ore.mithril`) | `best ≥ ORE_UNLOCK_LV.mithril`(12) | 3등급 |

### 생산
- 광석은 **사냥 1회(수동·자동 공통)마다** 지급: `ORE_PER_HUNT = {iron: 2, silver: 1, mithril: 0.5}` (해금된 광석만, m1-balance 확정).
- 소수 수량(미스릴 0.5)은 **정수부 + 소수부 확률**로 지급: `floor(rate) + (Math.random() < rate - floor(rate) ? 1 : 0)` → 미스릴은 사냥 1회당 50% 확률로 1개. 저장 필드 추가 없음.
- **자동 사냥·오프라인 보상은 같은 규칙**을 적용하되 오프라인은 기대값 `floor(n × ORE_PER_HUNT[k] × OFFLINE_EFF)`로 지급(확률 굴림 없음, m1-idle).
- 방치 성장 `up.gold`는 골드만 올리고 광석은 올리지 않음(광석은 사냥 횟수에 비례 → `up.speed`가 광석도 늘림).
- 광석 보유 상한 `ORE_MAX`=9,999.
- 대장간 탭에 3종 보유량과 "사냥당 획득량" 표시.

## 5. 장착/사용 흐름
1. 대장간 탭 모루 목록(카드): 등급, 내구도 바 `dura/ANVIL_DURA`, [장착] [수리](파손/손상 시) 버튼.
2. 장착 중 모루가 있고 파손이 아니면 소모품 트레이에 `🔨 {모루명} (내구 n/N, +b%p)` 토글 노출.
3. 시도 시 토글 ON이면 보너스 적용 + `dura -= 1`. 시도 직후 `dura==0`이 되면 토스트 "모루가 파손되었습니다(수리 필요)", 토글 자동 해제.
4. 파손 모루 장착 해제는 불필요. 다른 모루를 장착하면 `anvilEq`만 교체.
5. 내구도 소모는 **시도 시작 시(굴리기 전)** 차감 — 파괴 연출 도중 새로고침해도 소모가 보존되도록 시도 시작 시점에 저장.

## 6. 자원 균형 가이드 (밸런스 담당 참고)
- 철 모루 1개(내구 30)는 약 30회 강화에 +2%p → 다회 시도에 비해 비싸면 쓸 이유가 없음. "광석 제작 비용 < 상점가"가 되도록 `ANVIL_CRAFT`는 사냥 약 30회(철광석 60개) 수준(확정값과 근거는 m1-balance §2.4, §6.5).
- 3등급은 목표: 후반 +15~20 구간에서 사냥으로 모은 광석 수 시간 분량.

## 결정 사항 (사용자 확정, 2026-11-17)
1. 내구도 0인 모루는 삭제하지 않고 "파손" 상태로 보관하며 수리해 다시 쓴다(수리 기능 F8과 정합).
2. 내구도는 성공/실패/파괴를 가리지 않고 매 시도마다 1 소모한다(실패 시만 아님).

## 수용 기준 (Acceptance criteria)
1. Given `anvil_1`(dura 30)을 장착하고 +8 검에서 토글 ON일 때 / When 강화하면 / Then 성공 확률에 +2%p(합계 상한 내)가 반영되고 시도 직후 `dura=29`. 성공·실패·파괴 모두 -1.
2. Given 토글 OFF일 때 / When 강화하면 / Then `dura` 변화 없음.
3. Given `dura=1`인 모루로 강화 시도하면 / Then 시도 후 `dura=0`, 파손 토스트, 토글 해제, 장착은 유지, 다음 시도에서 보너스 0이며 토글이 비활성.
4. Given 파손 `anvil_2`, iron 40·silver 40 이상 보유 / When [수리]하면 / Then 광석이 해당만큼 줄고 `dura=40`.
5. Given 광석이 부족할 때 / Then [수리]/[제작] 버튼이 비활성이며 부족한 광석이 빨강으로 표시된다.
6. Given iron ≥ 60 / When `anvil_1`을 제작하면 / Then iron -60, 모루 목록에 `{g:1, dura:30}` 추가, `stats.crafted`+1. 모루가 `ANVIL_OWN_MAX`개면 제작/구매/교환이 거부된다.
7. Given 축복 주문서와 `anvil_3`를 같이 사용할 때 / Then 두 보너스는 합산 후 합계 상한(m1-pity-cap)을 적용받는다.
8. Given `best=6`일 때 / Then `ore_silver`/`ore_mithril`은 UI에 잠김으로 표시되며 사냥으로 증가하지 않는다. `best=7`이 되면 사냥당 은광석 +1. `best=12`가 되면 사냥 1회당 미스릴이 0 또는 1개 늘고, 사냥 1,000회 평균은 약 0.5개/회다. 오프라인 사냥 1,000회분(효율 25%)은 미스릴 정확히 `floor(1000×0.5×0.25)=125`개.
9. Given 수동 사냥 1회 / Then 골드와 함께 해금된 광석이 `ORE_PER_HUNT`만큼 증가한다.
10. Given 저장 후 새로고침 / Then 모루 목록·내구도·장착·광석이 복원된다.
