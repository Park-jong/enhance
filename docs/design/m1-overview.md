# M1 콘텐츠 확장 — 개요 (루프 · 자원 흐름 · 해금 · 화면 · 구현 순서)

> 상세는 각 문서: `m1-storage.md`(F5, 저장 구조) · `m1-protect-shards.md`(F2/F6) · `m1-anvil-ore.md`(F3/F8) · `m1-quest.md`(F4) · `m1-pity-cap.md`(F7+상한) · `m1-idle.md`(F1/F10/F9) · `m1-consumables.md`(F15) · `m1-constants-index.md`(상수 총람). 수치는 모두 잠정값, 확정은 `m1-balance.md`(밸런스 담당).

## 1. M1 이후 핵심 루프
1. **강화 루프(주)**: 보관함에서 검 클릭(활성) → 소모품 트레이에서 이번 시도에 쓸 것 선택(축복/모루/보호/하락방지/확정) → 성공률·파괴율 확인 → 강화 → 결과(성공/유지/하락/파괴/보호).
2. **수입 루프(보조)**: 사냥(수동) + 자동 사냥(방치) → 골드·광석. 오프라인 복귀 시 정산. 수입 단계 기준은 활성 검이 아니라 보관함 최고 단계 `topLv`(헬퍼 `topLv()`).
3. **관리 루프**: 보관함에 납품용 검을 따로 두고(F5) 의뢰(F4)를 채워 골드·소모품 획득. 파괴 시 파편(F6) → 보호권/모루 교환. 광석 → 모루 제작/수리(F8).
4. 판단 지점: ① 어떤 소모품을 쓸까(상한·잔여 보호 횟수 고려) ② 이 검을 계속 키울까/판매할까/납품용으로 둘까 ③ 골드를 시도·소모품·확장·방치 업그레이드 중 어디에 쓸까.

## 2. 자원 흐름
```
            ┌────────── 사냥(수동) / 자동 사냥 / 오프라인 ──────────┐
            ▼                                                        ▼
         [골드] ◄─ 판매 ─ [검]                                      [광석 iron/silver/mithril]
          │  ▲              │  ▲                                        │ 제작·수리
 상점구매 │  │ 납품(1.3~1.8×) │  │ 새검 구매(100G)/확장                    ▼
          ▼  │              ▼  │                                    [모루 anvil_1..3] ──┐
   [bless/protect/…/booster/seal] ◄── 퀘스트 보상 ── [의뢰 3슬롯]                       │ 성공률+
          ▲  │                          ▲                                               ▼
          │  └── 파편 교환 ◄── [파편] ◄─┘ 파괴(단계 비례)  ◄──────────── [강화 시도: 골드 소모]
          └───────────────────────────────────────────────────────────────────────────┘
```
| 자원 | 얻는 곳 | 쓰는 곳 |
| --- | --- | --- |
| 골드 | 판매, 납품, 사냥/자동/오프라인 | 강화 비용, 상점, 새 검, 칸 확장, 방치 업그레이드, 모루 제작(고급), 의뢰 새로고침 |
| 광석(철/은/미스릴) | 사냥(수동·자동·오프라인) | 모루 제작·수리 |
| 파편 | 검 파괴 | 소모품·모루 교환 |
| 소모품 | 상점, 파편, 퀘스트 보상 | 강화 시도/판매/사냥 보조 |
| 모루 | 상점(1등급), 제작, 파편, 퀘스트 | 강화 시도(내구도) |
| 퀘스트 토큰 | **없음**(보상은 골드·소모품·파편으로 직접 지급) | |

## 3. 해금 순서
| 요소 | 해금 조건 |
| --- | --- |
| 강화·판매·수동 사냥·상점(`bless`,`protect`) | 처음부터 |
| 보관함(3칸, 새 검 구매 100G) | 처음부터 |
| 연출 스킵 설정 | 처음부터 |
| 실패 보정(pity), 확률 상한 | 처음부터(자동 적용) |
| 파편/파괴 보호 UI | +5 이상 검을 가질 때부터 표시(파괴 가능 단계) |
| 대장간 탭(모루·광석·파편 교환) | `best ≥ 5` — 파편 교환 섹션도 대장간 탭 해금 시 항상 표시(파편 0개면 교환 버튼 전부 비활성 + "검이 파괴되면 파편을 얻습니다." 안내, 1개 이상이면 안내 숨김) (2026-11-19 변경) |
| 자동 사냥(F10) + 방치 업그레이드 + 오프라인 보상 | `best ≥ 5` 또는 명성 상점 자동 사냥 면허(`autoStart`) 보유 |
| 의뢰(F4) | `best ≥ 3` |
| 은광석 / 미스릴 광석 | `best ≥ 7` / `best ≥ 12` |
| `keepdown`, `sure` 상점 노출 | 처음부터 노출(해금 없음). 트레이에서 현재 단계에 무효이면 회색 |
| `booster`, `seal` 상점 | `best ≥ 5` |
| 상점 철 모루(`anvil_1`) | `best ≥ 5`(`FORGE_UNLOCK_BEST`). 그 전에는 잠금. 모루 토글은 활성 검 +5 이상(`ANVIL_TOGGLE_MIN_LV`) |
| 칸 확장 | 골드만(조건 없음) |
(잠긴 탭/섹션은 숨기지 않고 🔒 + 해금 조건 문구로 표시: 목표를 보이게 한다. 상수: `QUEST_UNLOCK_BEST`=3, `AUTO_UNLOCK_BEST`=5(명성 상점 자동 사냥 면허가 있으면 처음부터 해금), `FORGE_UNLOCK_BEST`=5.)

## 4. 화면/탭 구조
기존 단일 페이지(헤더 / 메인 카드 / 우측 사이드(상점·기록·로그) / 도감)를 다음처럼 변경.

### 데스크톱 (폭 > 720px)
- **헤더**: 로고 | 자원바(🪙골드, 💠파편, 광석 3종 — 해금된 것만) | ⚙설정(소리, 연출 스킵, 초기화) 
  - (2026-11-24 변경, 9-1 REQ-046) M2 이후 로고 뒤에 저장 실패 배지·시간 이벤트 칩·기념비 배지·칭호 배지가 붙는다(모두 상황에 따라 보임). 헤더는 **모든 폭에서** 항목이 한 줄에 다 들어가면 한 줄(배지가 없으면 데스크톱 높이 56px 그대로), 넘치면 남는 항목이 다음 줄로 내려간다. 가로 스크롤·항목 겹침이 없고, 로고는 줄어들거나 글자 단위로 꺾이지 않는다(한 줄). 항목(로고·배지·칩)은 줄어들지 않는다. 자원바·설정은 한 묶음(`.header-end`)으로 줄바꿈해, 다음 줄로 내려가도 둘이 함께 그 줄 오른쪽 끝에 붙는다(모든 폭, 설정 버튼만 홀로 왼쪽에 떨어지지 않음). 넓은 화면(721px 이상)에서 두 줄이 되면 오른쪽 탭 패널의 고정 위치(`top`)는 실제 헤더 높이 + 16px를 따른다(`--header-h`, `js/main.js`가 헤더 크기 변화 때 갱신).
- **좌측 컬럼(메인)**
  1. 보관함 스트립: 칸 카드 가로 나열(최대 8). 카드 **한 번 클릭/탭 = 그 검이 활성**([활성으로] 버튼 없음, 강화 연출 중·이미 활성인 검은 무시). 스트립 아래 줄에 활성 검 이름과 그 검에 적용되는 [판매][납품](활성 검이 없으면 "활성 검 없음 · 보관함에서 강화할 검을 선택하세요"만 표시). 카드를 끌어 칸 순서 변경(마우스: `DRAG_THRESHOLD_PX`=6px 이동 후 시작, 터치: `DRAG_LONG_PRESS_MS`=300ms 길게 누른 뒤 시작, 짧은 터치 이동은 스트립 가로 스크롤). 빈 칸 [+새 검], 잠금 칸 [확장]. (3-6, 2026-11-19 변경)
  - **활성 검 없음 상태**(활성 검이 파괴된 직후 `S.active=NO_ACTIVE_SWORD`=0, 자동 선택 안 함): 검 카드 영역에 `#stageEmpty` "보관함에서 강화할 검을 선택하세요", 검 이름 "활성 검 없음", 확률·비용·판매가는 `-`, 안내줄 "보관함의 검을 한 번 클릭하면 바로 활성 검이 됩니다.". [강화] 버튼은 비활성이며 "강화할 검을 선택하세요", [판매]도 비활성. 강화 단축키(Space 등)는 무시되고 규칙에서도 `attemptEnhance`가 `fail('noActive')`로 거부한다. 판매·납품으로 활성 검이 사라질 때만 남은 최고 검이 자동 활성이 된다.
  2. 검 카드(기존): 이름·무대·확률 4칸 정보(성공 확률에 분해 보조줄, 보정 게이지) · 경고 줄(보호 불가 등)
  3. 소모품 트레이(5행), 액션 버튼 [강화][판매][사냥] (+ 자동 사냥 토글 스위치 `⟳ 자동`)
  - **단축키 (2026-11-19 변경, REQ-031)**: Space=강화, S=판매, H=사냥, Escape=배너·모달·설정 닫기. Ctrl/Meta/Alt 조합은 무시한다. **글자를 넣는 칸**(textarea, select, contenteditable, 글자 입력형 input — 체크박스·라디오·버튼·range·color·file 등 비글자 input 제외)에 포커스가 있으면 단축키를 모두 무시한다(보호 모드 원문 칸 등에서 글자 입력·선택이 방해받지 않게). 체크박스·버튼 등에 포커스가 있을 때는 단축키가 기존대로 동작하며, Space의 keyup 기본 동작(포커스된 버튼·체크박스 재클릭)도 글자 입력 칸이 아닐 때만 막는다. 테스트: m1-storage AC 39.
- **우측 컬럼**: 탭 [상점] [대장간] [의뢰] [방치] [기록] — 한 번에 하나만. 기본 탭 상점. 로그는 [기록] 탭 하단(M2 이후에는 로그 아래에 업적 섹션).
  - (2026-11-24 확정, 9-1) **탭은 5개로 유지한다.** M2의 업적·일일 과제·칭호(F12), 환생·명성 상점(F11), 기념비(4-0)는 새 탭이 아니라 기록 탭의 섹션이다. 하단 탭바(모바일)도 5칸 그대로다.
  - 상점: 소모품 6종 + 모루 1등급 + 칸 확장
  - 대장간: 모루 목록(장착/수리), 제작, 광석 보유, 파편 교환
  - 의뢰: 3카드
  - 방치: 자동 사냥 상태, 업그레이드 3종, 부스터 사용 버튼, 오프라인 설명
  - 기록: 통계 + 로그 (M2 이후 섹션 순서: 환생·명성 상점 → 일일 과제 → 통계 → 숙련 → 기념비 → 로그 → 업적, `m2-rebirth.md` §7.1·`m2-achievements.md` §12)
- 도감(전폭)은 기존대로 하단.

### 모바일 (폭 ≤ 720px, 기존 미디어쿼리 재사용)
- 단일 컬럼 순서: 헤더(자원바는 2줄로 줄바꿈 허용) → 보관함 스트립(가로 스크롤, 카드 폭 64px) → 검 카드 → 소모품 트레이 → 액션 버튼(3개+토글) → **하단 고정 탭바**(상점/대장간/의뢰/방치/기록, 5탭) 위에 탭 콘텐츠가 검 카드 아래로 이어서 표시 → 도감.
- 탭 콘텐츠는 아코디언이 아닌 "선택된 탭 1개만" 표시(스크롤 길이 억제). 탭바 터치 영역 ≥ 44px. (2026-11-24 변경, 9-1) 기록 탭 버튼([환생]·명성 구매·받기·모두 받기·칭호 선택·기념비 [세우기])도 720px 이하에서 높이 44px 이상(데스크톱 크기는 그대로). 환생 확인 창 버튼은 원래 44px.
- 모달(오프라인 보상, 검 선택 액션)은 하단 시트 스타일.
- (2026-11-19 변경) 의뢰 탭은 알림 점이 아니라 탭 이름 옆 **숫자 뱃지**로 납품 가능한 의뢰 수(`Q.deliverableSlots(S).length`)를 보이며 0이면 숨긴다. 알림 점은 대장간=제작/수리 가능, 방치=업그레이드 구매 가능에만 남는다.

## 수용 기준 (Acceptance criteria)
