# M1 파괴 보호권(F2) + 파괴 파편(F6)

> 저장 필드는 `m1-storage.md` §3 참조 (`swords[].prot`, `inv.protect`, `shards`, `stats.protectSaved`, `stats.shardsGained`).

## 1. 결정 요약
| 항목 | 결정 |
| --- | --- |
| 기존 "파괴 방지권"과의 관계 | **통합(대체)**. 아이템 id `protect`, 표시명 "파괴 보호권"으로 이름만 바꾸고 기존 보유분은 1:1 승계. 별도 아이템을 만들지 않음 |
| 사용 제한 | 한 검이 **현재 단계에서 최대 `PROTECT_USES`(=2)회**까지만 보호 가능 (사용자 확정) |
| 횟수 카운터 | **검별** `sword.prot` (0..2) |
| 횟수 복구 | 그 검의 **단계가 바뀔 때마다**(성공으로 상승 **또는** 실패로 하락) 2로 복구 |
| 1회 보호에 필요한 장수 | 기존 `protectNeed(l) = 1 + ⌊l / PROTECT_NEED_DIV⌋` 유지(`PROTECT_NEED_DIV`=5). 즉 +5~9=2장, +10~14=3장, +15~19=4장 |
| 보호권 소모 시점 | **실제로 파괴를 막은 순간에만** 소모(M0와 동일). 파괴가 안 났으면 소모 없음 |
| 보호 불가 구간 | `DESTROY[l] = 0`인 +0~+4는 보호 UI를 표시하지 않음 |

## 2. 판단 근거
- **하락 시 초기화(예)**: "한 단계마다 2번"이라는 사용자 규칙을 "그 단계에 도착할 때마다 2번"으로 일관되게 해석. 단계별 사용 횟수 맵을 저장할 필요가 없고(검당 숫자 1개), UI도 "남은 N회" 하나로 끝남. 악용 여지: +12에서 2회 소진 → 비파괴 실패로 +11 하락 → 성공으로 +12 재도달 시 2회 복구. 이는 하락(골드·시간 손실)과 재상승 성공을 거친 대가이므로 허용. (대안: 단계별 맵 유지 — 구현·표시 복잡도 증가로 비권장)
- **검별 카운터**: 전역이면 검을 바꿔 가며 "횟수가 남은 검"만 위험 구간에 쓰는 것이 아니라 오히려 전역 1개 풀을 공유해 보관함의 의미가 사라짐. 검별이면 "이 검은 이미 +12에서 2번 구했다"가 검의 상태로 남아 보관함 선택에 판단이 생김.
- **통합**: 두 아이템(횟수제 보호/장수제 방지권)이 공존하면 UI·획득 경로가 중복되고 설명이 어려움. 장수 규칙(`protectNeed`)은 이미 검증된 M0 밸런스라 유지하고 횟수 상한만 추가.

## 3. 강화 시 처리 (의사코드)
```
canProtect = use.protect AND DESTROY[l] > 0 AND sword.prot > 0 AND inv.protect >= protectNeed(l)
파괴 판정 시:
  if canProtect:
      inv.protect -= protectNeed(l); sword.prot -= 1; stats.protectSaved++
      (검 유지, 단계 유지. 실패 처리와 달리 하락 없음. pity += 1)
  else: 파괴 (파편 지급, 칸 비움)
단계가 바뀌는 모든 경우(성공 l→l+1, 하락 l→l-1): sword.prot = PROTECT_USES
```
- 보호로 막은 시도는 "실패 0건 처리"가 아니라 **실패 보정(pity) +1로 센다**(m1-pity-cap 참조). 단계는 그대로이므로 `prot`는 초기화되지 않는다.

## 4. 표시 / 경고
- 소모품 트레이의 보호 행: `🛡️ 파괴 보호권 (보유 N장) · 이번 단계 보호 남은 횟수 ●●` — 남은 횟수만큼 채운 점, 사용한 만큼 빈 점(`●○`, `○○`).
- 보유 장수 < 필요 장수면 행 부제에 "필요 K장"을 빨강으로 표시하고 토글 비활성.
- **횟수 소진 경고**: `prot == 0`이고 `DESTROY[l] > 0`이면 (a) 보호 토글을 비활성(체크 해제)하고 (b) 파괴 확률 수치 옆에 `⚠ 보호 불가`를 빨강 뱃지로 표시, (c) 트레이 행에 "이 단계 보호 2/2 사용 — 파괴를 막을 수 없습니다" 문구, (d) 강화 버튼 부제를 "보호 없음"으로 바꾼다. 강화 자체를 막지는 않는다(단계가 바뀌면 복구됨을 안내: "성공하거나 하락하면 복구").
- 보관함 칸 카드에는 `🛡N`(N=prot) 표시, 0이면 회색 `🛡0`.
- 보호 성공 시 연출·문구는 M0 "보호됨!" 재사용 + 로그 "보호 K장 사용, 이 단계 남은 횟수 N".

## 5. 파괴 파편 (F6)
### 지급
파괴가 **확정(보호 실패/미사용)**되는 순간 지급. 보호로 막으면 지급 없음.
```
shardGain(l) = SHARD_BASE_PER_LV * l * (1 + floor(l / SHARD_BAND))
  잠정: SHARD_BASE_PER_LV = 1, SHARD_BAND = 5
  예) +5=10, +9=18, +10=30, +14=42(14*3), +15=60, +19=76
```
(파괴가 가능한 단계는 +5 이상뿐이므로 +5 미만은 정의 불필요.) 파괴 연출 중 결과 텍스트에 `+N 파편` 표시, 헤더 자원바의 파편 수치 갱신.

### 교환 (대장간 탭 "파편 교환")
파편은 되살리는 용도가 아니라 **"파괴의 보상으로 방어/성장 수단을 얻는" 용도**. 교환 품목과 비율(m1-balance 확정, 파편 1 ≈ 150G 환산):
| 품목 id | 파편 비용 상수 | 확정값 | 비고 |
| --- | --- | --- | --- |
| `bless` | `SHARD_COST.bless` | 10 | |
| `protect` | `SHARD_COST.protect` | 25 | 상점가 4,000G |
| `keepdown` | `SHARD_COST.keepdown` | 20 | |
| `sure` | `SHARD_COST.sure` | 10 | |
| `anvil_1` | `SHARD_COST.anvil_1` | 20 | |
| `anvil_2` | `SHARD_COST.anvil_2` | 50 | |
- `anvil_3`, `booster`, `seal`은 파편으로 교환 불가(광석 제작/상점/퀘스트 전용으로 경로를 분리).
- 교환은 1개 단위 버튼. 보유 상한(`STACK_MAX`=99, 모루는 `ANVIL_OWN_MAX`) 도달 시 비활성.
- 파편 보유 상한 없음.

## 열린 질문 (사용자 확인 필요)
1. 하락 시 보호 횟수 복구(권장: 복구). 비복구(단계별 맵)를 원하면 `prot`를 `{lv: used}` 맵으로 바꿔야 함.
2. 보호권 필요 장수를 유지할지(권장: 유지) vs 1장/회로 단순화.

## 수용 기준 (Acceptance criteria)
1. Given +12 검(`prot=2`), 보호 ON, `protect`=10장, 파괴가 판정될 때 / When 강화하면 / Then 검은 +12로 유지, `inv.protect`가 `protectNeed(12)=3` 감소, `prot=1`, `stats.protectSaved`+1, 파편 지급 없음.
2. Given 위 상황에서 두 번째 파괴 판정도 발생 / Then `prot=0`. 세 번째 파괴 판정 시 보호 ON이고 보호권이 충분해도 **파괴**되며 보호권은 소모되지 않는다.
3. Given `prot=0`인 +12 검일 때 / When 강화 화면을 보면 / Then 보호 토글이 비활성·해제 상태이고 `⚠ 보호 불가` 뱃지와 소진 안내 문구가 보인다.
4. Given `prot=0`인 +12 검이 +13으로 성공하면 / Then `prot=2`. 또한 +12 → +11 하락 시에도 `prot=2`.
5. Given 보호 ON이지만 파괴가 판정되지 않은 시도(성공/일반 실패)일 때 / Then 보호권·`prot`가 변하지 않는다.
6. Given 보호권이 `protectNeed(l)`보다 적을 때 / Then 토글은 비활성이고 필요 장수가 표시된다.
7. Given +10 검이 보호 없이 파괴될 때 / Then `shards`가 `shardGain(10)=30` 증가하고 `stats.shardsGained`가 같은 값 증가, 칸이 비워진다.
8. Given 보호로 막은 파괴일 때 / Then `shards` 변화 없음.
9. Given 파편 ≥ `SHARD_COST.protect`일 때 / When `protect` 교환을 누르면 / Then 파편이 그만큼 줄고 `inv.protect`+1. 파편 부족/상한 도달이면 버튼 비활성.
10. Given v1 저장에서 `inv.protect=5`일 때 / When 마이그레이션 / Then `inv.protect=5`이고 활성 검 `prot=2`.
11. Given +0~+4 검일 때 / Then 보호 토글/횟수 UI가 표시되지 않는다.
