## 3. 출시 후 다시 볼 것
1. 위 A~F 손잡이. 플레이 테스트 기록(체크리스트 §1·§3 표)이 생기면 그때 판정한다.
2. **환생 미러 키의 남은 틈(수용)**: 옛 탭이 환생 전 상태로 검을 더 사서 `nextSwordId`가 기준값을 넘기면 미러가 다시 합쳐지는 경우, 새 게임의 저장 키 쓰기가 실패하거나 보호 모드일 때 미러가 낮아지지 않는 경우 (`m2-rebirth.md` §8.2 "남은 틈").
3. **`SUCC_CEIL`(90)은 상수상 닿지 않음**: 밴드 1에서 `base + 20 ≤ 90`(+5는 70+20 = 90으로 정확히 천장)이라 식만 남겨 둔 것이다. 상수를 바꾸면 의미가 살아난다 (`m2-events.md` §5 부근, 인수 기준 11·12가 주입값으로 검사).
4. **일일 과제 카운트다운**: 서머타임 전환 밤에는 "다음 갱신까지" 표시가 1시간 어긋날 수 있다(`m2-achievements.md` §12 UI 문구; 전환은 대부분 01~03시라 새 날 경계는 영향이 적고 `maxDay`가 역행을 흡수한다).
5. 문서의 "잠정/초안" 표기: 환생 페이스(`m2-rebirth.md` §6·§15.6), 업적·이벤트 일부 값은 위 측정 전까지 초안으로 남는다.
6. 일반 규칙: 상수를 바꾸면 `m1-constants-index.md` §9와 해당 기획서 값을 같이 고친다(V5, `docs/verification-issues.md`).
