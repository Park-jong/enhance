## M1 기능 요구사항 (사용자 요청, 2026-11-17)

### F1. 방치형 요소
- 직접 누르지 않아도 시간이 지나면 자원이 쌓이는 구조를 넣는다.
- 현재: 사냥 버튼(2.5초 쿨다운, 들고 있는 검이 강할수록 보상 증가)만 있음.
- 기획에서 정할 것: 자동 수입 방식(자동 사냥 등), 오프라인 보상과 상한 시간, 방치 수입을 키우는 성장 요소, 강화 루프와의 밸런스.

### F2. 방어 요소: 파괴 보호권 (강화 당 2회)
- 강화 실패로 검이 파괴될 때 막아 주는 방어 수단을 정비한다.
- 사용자 지정 조건: "강화 당 2회" = **한 단계마다 보호를 최대 2번까지 쓸 수 있음** (2026-11-17 확정)
  - 예: +12에서 파괴될 상황을 두 번 막은 뒤, 세 번째 파괴는 보호권이 있어도 막지 못함. +13으로 성공하면 횟수가 다시 2번으로 돌아옴
  - 단계가 하락(+12 → +11)했을 때 횟수를 초기화할지는 기획 팀이 정함
- 현재: 파괴 방지권은 파괴 시 소모되며, 필요 장수가 단계에 따라 늘어남(1 + ⌊단계/5⌋장). 횟수 제한은 없음.
- 기획에서 정할 것: 남은 보호 횟수 표시 방법, 기존 파괴 방지권과의 관계(대체/병행), 획득 경로와 가격.

### F3. 소모품 요소: 모루
- 강화할 때 쓰는 장비형 소모품. 모루 등급이 높을수록 강화 성공 확률이 오른다.
- 내구도가 있어 사용할수록 닳고, 다 닳으면 사라지거나 교체해야 한다.
- 기획에서 정할 것: 등급 수와 등급별 확률 보너스, 내구도 수치와 소모 조건(시도마다/실패 시만), 획득 경로(상점/퀘스트/제작), 축복 주문서와 중첩 여부.

### F4. 퀘스트 요소: 납품
- 의뢰인이 특정 강화 단계의 검을 요구하고, 납품하면 보상을 준다.
- 기획에서 정할 것: 의뢰 생성 규칙(요구 단계, 갱신 주기, 동시 의뢰 수), 보상 종류(골드, 모루, 보호권 등), 판매와 비교했을 때의 이점, 납품하면 검이 사라지는지 여부.

### F5. 검 보관함 (여러 자루 보유)
- 검을 여러 자루 가지고, 그중 한 자루를 골라 강화한다. 납품용 검을 따로 보관하면서 주력 검을 계속 키울 수 있게 하는 것이 목적.
- 저장 구조와 화면 배치가 크게 바뀌므로 M1에서 가장 먼저 확정해야 한다.
- 기획에서 정할 것: 보관 칸 수와 확장 방법, 새 검(+0)을 얻는 방법, 보관함에서 바로 판매·납품할 수 있는지.

### F6. 파괴 파편
- 검이 파괴되면 단계에 비례한 파편을 얻는다. 파편은 보호권이나 모루로 바꿀 수 있다.
- 기획에서 정할 것: 단계별 파편 양, 교환 비율, 교환 가능한 품목.

### F7. 실패 보정 (천장)
- 실패할 때마다 다음 강화 성공 확률이 조금씩 오르고, 성공하면 초기화된다.
- 기획에서 정할 것: 단계별 증가량과 최대치, 파괴·하락 시 보정을 유지할지, 보정 수치 표시 방법.

### F8. 광석과 모루 제작·수리
- 방치형 수입으로 골드와 함께 광석이 쌓이고, 광석으로 모루를 만들거나 닳은 모루를 고친다. F1과 F3를 잇는 요소.
- 기획에서 정할 것: 광석 종류와 획득량, 모루 등급별 제작·수리 비용.

### F9. 강화 연출 스킵
- 강화할 때 나오는 연출(충전 0.65초, 결과 표시, 파괴 애니메이션)을 건너뛰는 옵션.
- 현재: 강화 1회마다 연출이 끝날 때까지 다음 강화를 할 수 없음.
- 정할 것: 켜고 끄는 방식(설정 토글), 스킵 중에도 남길 최소한의 피드백(결과 텍스트, 효과음 등), 높은 단계 성공·파괴처럼 중요한 결과는 스킵 중에도 보여 줄지.

### F10. 골드 자동 수급 버튼
- 버튼을 켜 두면 골드가 자동으로 들어온다 (예: 자동 사냥 켜기/끄기). F1 방치형 요소의 일부.
- 현재: 사냥 버튼을 2.5초마다 직접 눌러야 함.
- 기획에서 정할 것: 수동 사냥 대비 효율, 해금 조건(처음부터/구매/단계 달성), 오프라인 보상과의 관계.

### F15. 소모품 추가
- 축복 주문서·파괴 보호권·모루 외에 소모품 종류를 더 늘린다. 상황에 맞춰 어떤 소모품을 쓸지 고르는 판단을 강화 루프에 더하는 것이 목적.
- 후보 예시 (기획 팀이 취사선택·추가):
  - 하락 방지 주문서: +10 이상에서 실패해도 단계가 내려가지 않음
  - 확정 강화권: 일정 단계 이하(예: +10까지)에서 1회 100% 성공
  - 단계 복구권: 파괴된 검을 파괴 직전보다 한 단계 낮은 상태로 되살림
  - 행운의 부적: 일정 시간 동안 성공 확률 상승
  - 골드 부스터: 일정 시간 동안 사냥·방치 수입 증가
  - 감정 인장: 다음 판매·납품 보상 증가
  - 의뢰 갱신권: 납품 의뢰 목록 새로고침
- 기획에서 정할 것: 최종 품목과 효과 수치, 획득 경로(상점, 납품 보상, 파편 교환, 광석 제작), 가격, 다른 소모품과 같이 쓸 수 있는지, 확률 보너스 상한에 포함되는지.

### 공통 주의사항 (M1 전체)
- **확률 보너스 상한**: 축복 주문서(M0 기존), 모루(F3), 실패 보정(F7)이 겹치면 높은 단계 성공 확률이 너무 쉽게 오른다. 보너스 합계의 최대치를 정한다.
- **저장 데이터 이전**: 저장 구조가 바뀌므로 기존 저장(`sword-enhance-v1`)을 새 버전으로 옮기는 처리가 필요하다.

## M2 기능 요구사항 (사용자 요청, 2026-11-17)

### F11. 환생 (대장간 명성)
- +20 달성 후 처음부터 다시 시작하는 대신 영구 보너스(방치 수입, 기본 성공 확률 등)를 받는다.

### F12. 업적과 일일 의뢰
- "파괴 10회", "+15 달성" 같은 업적과 매일 바뀌는 목표.

### F13. 시간 이벤트
- 가끔 열리는 한시 버프 (예: 5분간 성공 확률 +5%p).

### F14. 검 랜덤 특성
- 같은 단계의 검이라도 "사냥 보상 +20%", "판매가 +15%" 같은 특성이 붙는다.
